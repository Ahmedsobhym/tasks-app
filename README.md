# ✨ مهامي — لوحة إدارة المهام اليومية

تطبيق ويب خفيف لإدارة المهام اليومية، يعمل مباشرة من المتصفح دون تثبيت أو خادم أو قاعدة بيانات.
التطبيق كله ملف واحد: `index.html`.

## المزايا

- **ثلاث حالات للمهام:** 🗓️ مخطط لها، ⚡ قيد العمل، ✅ منتهية.
- **أقسام رئيسية ملوّنة:** العمل، شخصي، الصحة والرياضة، التعلم، المنزل. يمكنك إضافة أقسام وتعديل اسمها وأيقونتها ولونها.
- **نقل المهام** بالسحب والإفلات، أو بأسهم البطاقة على الجوال.
- **لكل مهمة:** عنوان، ملاحظات، قسم، أولوية (عالية / متوسطة / منخفضة)، وموعد تنفيذ.
- **لوحة إحصاءات** بنسبة الإنجاز وعدد المهام قيد العمل والمنتهية والمتأخرة.
- **فلاتر:** الكل، اليوم، هذا الأسبوع، المتأخرة، مع بحث فوري.
- **وضع ليلي ونهاري** 🌙☀️.
- **نسخ احتياطي واستعادة:** تنزيل ملف JSON بالبيانات أو استعادته.
- **اختصارات:** `N` لإضافة مهمة، `/` للبحث، `Esc` للإغلاق.
- واجهة عربية بالكامل من اليمين لليسار، ومتجاوبة مع الجوال.

## طريقة الاستخدام

### الطريقة 1: على جهازك
1. حمّل المستودع من زر **Code ← Download ZIP**.
2. فك الضغط وافتح ملف `index.html` بأي متصفح.

### الطريقة 2: نشره على الإنترنت عبر GitHub Pages
1. ارفع الملفات إلى مستودع على GitHub.
2. ادخل **Settings ← Pages**.
3. من **Source** اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
4. بعد دقيقة تقريبًا يصبح التطبيق متاحًا على الرابط:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## أين تُحفظ البيانات؟

تُحفظ المهام في **ذاكرة المتصفح (localStorage)** على جهازك فقط، فلا تُرسل إلى أي خادم.
لذلك:
- كل مستخدم له مهامه الخاصة على جهازه.
- مسح بيانات المتصفح يحذف المهام، فاستخدم زر 💾 لتنزيل نسخة احتياطية من وقت لآخر.
- لنقل مهامك إلى جهاز آخر: نزّل النسخة من الجهاز الأول، ثم استعدها من زر 💾 في الجهاز الثاني.
